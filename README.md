# SportShop — практическое занятие 9

Учебный проект демонстрирует разбиение приложения на модули, интеграцию корзины с каталогом и заказами, JSON-хранилище и локальную сборку.

## Запуск

Нужен Python 3.10 или новее. Из корневой папки проекта выполните:

```bash
python build.py
```

Скрипт проверит версию Python и файл `data/products.json`, запустит 14 тестов, а затем покажет демонстрационный сценарий приложения. Отдельно все тесты можно запустить командой `python -m unittest discover -s tests`.

## Состав

- `src/` — каталог, корзина, заказы, аналитика и JSON-хранилище.
- `tests/` — модульные и интеграционные тесты.
- `data/products.json` — пример каталога.
- `docs/15_Integration_Errors.md` — эксперимент с несовместимым форматом данных.
- `docs/16_Integration_Report.md` — отчёт по интеграции.
- `BUILD_OUTPUT.txt` — фактический успешный вывод `python build.py`.
