# СпортТовары — система управления магазином

Учебное консольное приложение на Python для работы с каталогом спортивных товаров, корзиной, заказами и простой аналитикой. Данные каталога и заказы хранятся в JSON. SQLite и внешние пакеты не требуются.

## Требования

- Python 3.10 или новее.
- Git — для клонирования репозитория и работы с версиями.

## Установка

```bash
git clone <URL-репозитория>
cd SportShop
```

Приложение использует только стандартную библиотеку Python, поэтому устанавливать дополнительные пакеты не нужно.

## Запуск

```bash
python main.py
```

Программа загружает `data/products.json`, показывает каталог с низким остатком, ищет кроссовки и демонстрирует добавление товара в корзину и оформление заказа.

## Тестирование и сборка

```bash
python -m unittest discover -s tests
python build.py
```

Первая команда запускает все 14 модульных и интеграционных тестов. Сборочный скрипт проверяет версию Python и файл данных, запускает тесты и демонстрационное приложение.

## Структура проекта

```text
SportShop/
├── src/
│   ├── __init__.py
│   ├── catalog.py       # каталог и поиск
│   ├── cart.py          # корзина
│   ├── orders.py        # создание и хранение заказов
│   ├── analytics.py     # расчёты по заказам
│   └── storage.py       # каталог в JSON
├── tests/               # модульные и интеграционные проверки
├── docs/                # отчёты и документация
├── data/products.json   # демонстрационный каталог
├── main.py              # запуск приложения
├── build.py             # проверка, тесты и запуск
└── README.md
```
