# Справочник API

Публичные функции модулей `src`. Исключения, связанные с некорректными данными или файлами, указаны для практических сценариев использования.

## `src.catalog`

### `get_low_stock(products, limit=3)`
Находит товары, суммарный остаток которых не превышает `limit`; сортирует по остатку и названию.

- **Параметры:** `products` — итерируемые словари товара; `limit` — целочисленная верхняя граница остатка, по умолчанию 3.
- **Возвращает:** список словарей товаров.
- **Исключения:** `ValueError`, если остаток в исходных данных нельзя преобразовать в целое число.
- **Пример:** `get_low_stock(load_products("data/products.json"))`.

### `search_advanced(products, query="", category=None, min_price=None, max_price=None)`
Ищет по названию и бренду без учёта регистра, применяя при необходимости категорию и границы цены.

- **Параметры:** список `products`; подстрока `query`; `category`; минимальная `min_price` и максимальная `max_price` цена.
- **Возвращает:** список совпавших товаров; пустой запрос даёт пустой список.
- **Исключения:** `ValueError`, если одновременно заданы границы цены и `min_price > max_price`.
- **Пример:** `search_advanced(products, "кроссовки", category="Обувь", max_price=5000)`.

### `count_by_category(products)`
Подсчитывает число записей товара по категориям.

- **Параметры:** итерируемый набор словарей `products`.
- **Возвращает:** словарь `{название_категории: количество}`; у товара без категории используется «Без категории».
- **Исключения:** нет для корректных словарей.
- **Пример:** `count_by_category(products) -> {"Обувь": 1, "Одежда": 1}`.

### `avg_price(products)`
Рассчитывает среднюю цену записей каталога.

- **Параметры:** итерируемый набор словарей `products`.
- **Возвращает:** `float`; для пустого каталога — `0.0`.
- **Исключения:** `ValueError`, если цена непредставима как число.
- **Пример:** `avg_price(products) -> 3166.67` (значение зависит от каталога).

## `src.cart`

### `add_to_cart(cart, products, product_id, size, quantity)`
Добавляет товар указанного размера в корзину или увеличивает количество существующей позиции.

- **Параметры:** изменяемый список `cart`; каталог `products`; идентификатор `product_id`; размер `size`; положительное целое `quantity`.
- **Возвращает:** `(успех: bool, сообщение: str)`.
- **Исключения:** в обычных пользовательских ошибках не выбрасывает исключение, а возвращает `False` и причину.
- **Пример:** `add_to_cart(cart, products, 1, 40, 2)`.

### `remove_from_cart(cart, product_id, size)`
Удаляет из корзины позицию с совпавшими идентификатором и размером.

- **Параметры:** список `cart`, `product_id`, `size`.
- **Возвращает:** `True`, если позиция удалена, иначе `False`.
- **Исключения:** нет для корректного списка словарей.
- **Пример:** `remove_from_cart(cart, 1, 40)`.

### `update_quantity(cart, products, product_id, size, new_qty)`
Изменяет количество позиции, не превышая остаток товара.

- **Параметры:** корзина `cart`, каталог `products`, идентификатор, размер, новое положительное количество `new_qty`.
- **Возвращает:** `True` при изменении, иначе `False`.
- **Исключения:** нет для корректного формата данных.
- **Пример:** `update_quantity(cart, products, 1, 40, 3)`.

### `cart_total(cart)`
Суммирует стоимость корзины с учётом количества каждой позиции.

- **Параметры:** итерируемый список позиций `cart` с `price` и `quantity`.
- **Возвращает:** общую сумму типа `float`; пустая корзина даёт `0`.
- **Исключения:** `ValueError`/`TypeError` для цены или количества некорректного типа.
- **Пример:** `cart_total([{"price": 100, "quantity": 2}]) -> 200.0`.

## `src.orders`

### `create_order(cart, client_name, products)`
Создаёт снимок заказа из непустой корзины, если товары присутствуют в каталоге.

- **Параметры:** позиции `cart`, непустое имя `client_name`, каталог `products`.
- **Возвращает:** словарь с `client_name`, копией `items` и `total`, либо `None` при пустой/невалидной корзине.
- **Исключения:** нет для корректных входных структур.
- **Пример:** `order = create_order(cart, "Анна", products)`.

### `print_order(order)`
Формирует и печатает текстовое представление заказа.

- **Параметры:** словарь `order` с именем клиента, позициями и итогом.
- **Возвращает:** напечатанную строку.
- **Исключения:** `KeyError`, если в заказе отсутствуют обязательные поля.
- **Пример:** `print_order(order)`.

### `save_orders(orders, filename)`
Сохраняет список заказов в JSON UTF-8; создаёт родительскую папку, если её нет.

- **Параметры:** список словарей `orders`, путь `filename`.
- **Возвращает:** `None`.
- **Исключения:** `OSError` при ошибке записи; `TypeError` для данных, которые JSON не может сериализовать.
- **Пример:** `save_orders([order], "data/orders.json")`.

### `load_orders(filename)`
Читает список заказов из JSON UTF-8.

- **Параметры:** путь `filename`.
- **Возвращает:** список словарей заказов.
- **Исключения:** `FileNotFoundError`, `OSError`, `json.JSONDecodeError`; `ValueError`, если корневое значение JSON не список.
- **Пример:** `orders = load_orders("data/orders.json")`.

## `src.analytics`

### `total_revenue(orders)`
Суммирует поле `total` всех заказов.

- **Параметры:** итерируемые словари `orders`.
- **Возвращает:** общую выручку `float`; пустой набор — `0`.
- **Исключения:** `ValueError`/`TypeError` для некорректных сумм.
- **Пример:** `total_revenue(orders) -> 9000.0`.

### `best_selling_product(orders)`
Возвращает название товара с наибольшим общим количеством проданных единиц.

- **Параметры:** заказы с массивом `items`, где есть `name` и `quantity`.
- **Возвращает:** название `str`; `None`, если продаж нет.
- **Исключения:** `ValueError`/`TypeError` при некорректном количестве.
- **Пример:** `best_selling_product(orders) -> "Кроссовки Sprint"`.

### `average_order_total(orders)`
Рассчитывает среднюю сумму заказа.

- **Параметры:** итерируемый набор заказов с полем `total`.
- **Возвращает:** среднее `float`; для пустого набора — `0.0`.
- **Исключения:** `ValueError`/`TypeError` при некорректных суммах.
- **Пример:** `average_order_total(orders) -> 9000.0`.

## `src.storage`

### `load_products(filename)`
Загружает каталог из JSON-файла и проверяет, что корневое значение является списком.

- **Параметры:** путь `filename`.
- **Возвращает:** список словарей товара.
- **Исключения:** `FileNotFoundError`, `OSError`, `json.JSONDecodeError`; `ValueError`, если JSON не содержит список.
- **Пример:** `products = load_products("data/products.json")`.

### `save_products(products, filename)`
Сохраняет список товаров в JSON UTF-8.

- **Параметры:** список `products`, путь `filename`.
- **Возвращает:** `None`.
- **Исключения:** `OSError` при ошибке записи; `TypeError` для несериализуемых значений.
- **Пример:** `save_products(products, "data/products_backup.json")`.
