# Руководство разработчика

## Настройка окружения

1. Установите Python 3.10 или новее и Git.
2. Клонируйте репозиторий и перейдите в папку проекта:

   ```bash
   git clone <URL-репозитория>
   cd SportShop
   ```

3. Приложение зависит только от стандартной библиотеки, поэтому отдельная установка пакетов не требуется.

## Тесты и локальная сборка

Запуск всего набора тестов:

```bash
python -m unittest discover -s tests
```

Полная проверка с демонстрационным запуском приложения:

```bash
python build.py
```

Сборка завершится с ненулевым кодом, если Python старше/младше требуемой версии, каталог отсутствует, тесты завершились ошибкой или приложение не запустилось.

## Как добавить новую функцию

1. Определите, к какому модулю относится задача: `catalog`, `cart`, `orders`, `analytics` или `storage`.
2. Добавьте функцию в этот модуль и документируйте параметры, результат и ошибки.
3. Если функция нужна пользователю, подключите её в `main.py`.
4. Добавьте модульные тесты в подходящий файл `tests/test_*.py`; если затронуты стыки модулей, обновите `tests/test_integration.py`.
5. Запустите `python -m unittest discover -s tests` и `python build.py`.
6. Обновите справочник API и руководство пользователя, если изменилось пользовательское поведение.

## Ветка и Pull Request

Создайте feature-ветку от актуального `main`, вносите изменения в неё и отправьте на сервер:

```bash
git checkout main
git pull
git checkout -b feature/название-функции
git add src tests docs
git commit -m "Добавлена новая функция"
git push -u origin feature/название-функции
```

На GitHub откройте Pull Request из `feature/название-функции` в `main`, укажите описание и результаты проверок, дождитесь ревью и слейте изменения по правилам команды.

## Сборка и версия

`build.py` автоматически проверяет версию Python и каталог данных, запускает тесты, затем стартует `main.py`. Релизная версия отмечается тегом Git, например `v1.0`.
